# System Architect Portfolio

A premium personal website built with React, Tailwind CSS, and Framer Motion.

## Tech Stack
- **Framework:** React (Vite)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Fonts
This project is designed to use **HarmonyOS Sans**. 
If you have the font installed locally on your machine, the website will automatically use it.
Otherwise, it will gracefully fall back to **Inter** (Google Fonts), which provides a similar clean, system-focused aesthetic.

## Customization
- **Colors:** Edit `tailwind.config.js` to adjust the color palette.
- **Content:** Modify the component files in `src/sections/` to update text and data.
